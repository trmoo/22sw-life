## 생각 열기 — 우리 반에 생일이 같은 친구가 있을까

<InfoBox variant="think" label="함께 생각해 보기">
1년은 365일이다. 반 학생이 23명이라면, 생일이 같은 두 사람이 있을 확률은 얼마쯤일까? 10%? 30%? 50% 넘게? 짐작한 값을 적어 두고 이 차시 끝에서 견주어 보자.
</InfoBox>

## 컴퓨터가 우연을 흉내 내는 법 — 난수

<Term ko="난수" en="random number" desc="미리 짐작할 수 없게 고르게 흩어져 나오는 수. 컴퓨터는 정해진 계산으로 난수처럼 보이는 수를 만든다" />는 짐작할 수 없게 나오는 수다. 파이썬에서는 `random` 모듈이 만들어 준다.

<CompareTable

  ]}
/>

<InfoBox variant="info" label="씨앗을 정하는 까닭">
아래 예제들은 `random.seed(…)` 로 씨앗을 정해 두었다. 그래서 몇 번을 실행해도 «확인된 실행 결과»와 똑같은 결과가 나온다. 씨앗 줄을 지우거나 숫자를 바꿔 실행하면 결과가 달라진다 — **고치기**를 눌러 직접 해 보자.
</InfoBox>

## 몬테카를로 시뮬레이션

<Term ko="몬테카를로 방법" en="Monte Carlo method" desc="난수로 같은 실험을 아주 많이 되풀이해 확률이나 값을 어림하는 방법. 이름은 모나코의 도박장 거리에서 따왔다" />은 난수로 같은 실험을 아주 많이 되풀이해 답을 어림하는 방법이다. 이름은 모나코의 도박장으로 유명한 곳 이름에서 따왔다. 공식을 몰라도, 너무 복잡해 공식으로 풀 수 없어도, «실험을 많이 하면» 답에 다가갈 수 있다.

### 점을 던져 원주율 구하기

한 변이 1인 정사각형에 점을 아무렇게나 던진다. 왼쪽 아래 꼭짓점을 중심으로 한 반지름 1인 사분원의 넓이는 π/4, 정사각형의 넓이는 1이다. 그러니 **사분원 안에 든 점의 비율 × 4 ≈ π** 다.

<MonteCarloPi id="u4-l6-pi" />

<Activity kind="시뮬레이터" title="원주율 어림하기" time={10}>

1. **+10** 을 세 번 눌러 보자. 어림값이 3.14 에 가까운가?
2. **+1,000** 과 **+100,000** 을 눌러 보자. 그래프의 선은 어떻게 움직이는가?
3. 옆 친구의 값과 견주어 보자. 같은가? 둘 다 3.14 근처인가?

</Activity>

같은 실험을 파이썬으로 하면 이렇다.

<CodeSample lang="python" caption="몬테카를로로 원주율 어림하기" expect={"100 2.84\n1000 3.152\n10000 3.1368\n100000 3.14204\n"}>
{`import random

random.seed(4)
for n in [100, 1000, 10000, 100000]:
    안 = 0
    for _ in range(n):
        x, y = random.random(), random.random()
        if x * x + y * y <= 1:
            안 += 1
    print(n, 4 * 안 / n)`}
</CodeSample>

100개만 던지면 2.84 로 꽤 틀리지만, 10만 개를 던지면 3.142 로 소수 셋째 자리까지 맞는다. 다만 10,000개일 때(3.1368)가 1,000개일 때(3.152)보다 오히려 조금 더 멀다 — 난수라서 **늘 차근차근 다가가는 것은 아니고, 크게 보면 다가간다.** 많이 되풀이할수록 어림값이 참값에 가까워지는 성질을 <Term ko="대수의 법칙" en="law of large numbers" desc="같은 시행을 많이 되풀이할수록 결과의 비율이 실제 확률에 가까워진다는 성질" />이라 한다.

## 생일 문제

이제 생각 열기의 물음으로 돌아가자. 365일 가운데 아무 날이나 생일로 뽑아 반을 만들고, 생일이 같은 사람이 있는지 본다. 이것을 5,000번 되풀이해 «있었던 비율»을 센다.

<CodeSample lang="python" caption="생일 문제 — 반마다 5,000번 실험" expect={"10명: 0.110\n23명: 0.510\n30명: 0.703\n40명: 0.884\n"}>
{`import random

random.seed(7)

def 같은생일있나(사람):
    생일 = [random.randint(1, 365) for _ in range(사람)]
    return len(set(생일)) < 사람   # 겹치면 집합이 작아진다

for 사람 in [10, 23, 30, 40]:
    횟수 = 5000
    있음 = sum(같은생일있나(사람) for _ in range(횟수))
    print(f'{사람}명: {있음 / 횟수:.3f}')`}
</CodeSample>

23명만 모여도 생일이 같은 두 사람이 있을 확률이 **절반쯤**이다. 많은 사람이 짐작보다 훨씬 크다고 놀란다. 공식으로도 풀 수 있지만(23명이면 약 0.507), 공식을 몰라도 실험을 되풀이해 거의 같은 답을 얻었다. 이것이 몬테카를로 시뮬레이션의 힘이다.

<InfoBox variant="tip" label="왜 그렇게 클까">
23명이면 두 사람씩 짝지을 수 있는 경우가 23 × 22 ÷ 2 = **253쌍**이다. 「나와 생일이 같은 사람」이 아니라 「253쌍 가운데 어느 한 쌍이라도 같은 경우」를 묻는 것이라 확률이 커진다.
</InfoBox>

## 그래프로 보기 — 주사위 두 개

주사위 두 개를 10,000번 던져 눈의 합이 몇이 몇 번 나오는지 히스토그램으로 그린다(Ⅲ단원의 맷플롯립).

<CodeSample lang="python" caption="주사위 두 개 눈의 합" plot="u4-l6-dice" expect={"7이 나온 비율: 0.1675\n"}>
{`import random
import matplotlib.pyplot as plt

random.seed(1)
합들 = [random.randint(1, 6) + random.randint(1, 6) for _ in range(10000)]

plt.figure(figsize=(6, 3.5))
plt.hist(합들, bins=range(2, 14), align='left', rwidth=0.8)
plt.title('주사위 두 개 눈의 합 — 10,000번')
plt.xlabel('눈의 합')
plt.ylabel('나온 횟수')
plt.xticks(range(2, 13))
plt.show()
print('7이 나온 비율:', 합들.count(7) / 10000)`}
</CodeSample>

7이 가장 많이 나온다. 7을 만드는 방법이 (1,6) (2,5) (3,4) (4,3) (5,2) (6,1) 여섯 가지로 가장 많기 때문이다. 이론으로는 6/36 ≈ 0.167 이다.
