## 생각 열기 — 퍼지는 것은 어떻게 퍼질까

반에 감기 걸린 친구가 한 명 있다. 처음에는 몇 명 안 되던 환자가 어느 날 갑자기 많아지고, 또 어느새 줄어든다.

<InfoBox variant="think" label="함께 생각해 보기">
왜 처음에는 천천히 늘다가 갑자기 늘어날까? 그리고 왜 결국 줄어들까 — 아무도 약을 먹지 않아도?
</InfoBox>

<InfoBox variant="warn" label="이 차시의 모델에 대하여">
이 차시의 시뮬레이션은 **퍼지는 현상의 원리를 이해하려는 학습용 모델**이다. 숫자는 모두 설명을 위해 정한 값이고, 실제 어떤 감염병을 예측하지 않는다. 실제 방역 결정에는 훨씬 많은 요소와 실제 자료가 쓰인다.
</InfoBox>

규칙은 둘이다. ① S 가 I 를 만나면 어떤 확률로 I 가 된다. ② I 는 시간이 지나면 R 이 된다. 처음에 천천히 느는 까닭은 I 가 적어서 만남이 적기 때문이고, 결국 줄어드는 까닭은 **옮을 수 있는 S 가 줄어들기 때문**이다.

## 곡선 평탄화

거리 두기나 손 씻기로 β 를 낮추면 걸리는 사람이 줄 뿐 아니라, **한꺼번에 앓는 사람의 정점이 낮아지고 늦춰진다.** 병원의 병상은 한정되어 있으므로 정점이 낮아지는 것만으로도 큰 차이가 난다. 이를 «곡선을 평탄하게 만든다»고 한다.

먼저 식으로 보기의 계산을 파이썬으로 옮겨 보자. 규칙 두 줄이 그대로 코드 두 줄이 된다.

<CodeSample lang="python" caption="SIR 모델 — 하루씩 계산하기" expect={"앓는 사람이 가장 많은 날: 41 일째\n그날 앓는 사람: 3127 명\n160일 뒤 한 번도 안 걸린 사람: 533 명\n"}>
{`N, I, R = 10000, 10, 0
S = N - I - R
beta, gamma = 0.3, 0.1        # 하루에 옮기는 정도, 하루에 낫는 비율

앓는사람 = [I]
for 날 in range(1, 161):
    새감염 = beta * S * I / N
    새회복 = gamma * I
    S, I, R = S - 새감염, I + 새감염 - 새회복, R + 새회복
    앓는사람.append(I)

정점 = max(앓는사람)
print('앓는 사람이 가장 많은 날:', 앓는사람.index(정점), '일째')
print('그날 앓는 사람:', round(정점), '명')
print('160일 뒤 한 번도 안 걸린 사람:', round(S), '명')`}
</CodeSample>

`S, I, R = …` 처럼 세 값을 **한 줄에서 함께** 바꾸는 것이 중요하다. 따로 세 줄로 쓰면 S 를 먼저 바꾼 뒤 그 새 S 로 I 를 계산하게 되어 결과가 달라진다. 이 계산은 시뮬레이터의 「식으로 보기」와 같은 식이며, 교과서를 만들 때 두 결과가 같은지 컴퓨터로 대조했다.

이제 β 를 반으로 줄였을 때와 견주어 그래프로 그린다.

<CodeSample lang="python" caption="곡선 평탄화 — β 0.3 과 0.15" plot="u4-l7-flat" expect={"β=0.3: 정점 41일째, 3127명\nβ=0.15: 정점 116일째, 646명\n"}>
{`import matplotlib.pyplot as plt

def 확산(beta, gamma=0.1, N=10000, I=10, 일수=160):
    S, R = N - I, 0
    앓는사람 = [I]
    for _ in range(일수):
        새감염 = beta * S * I / N
        새회복 = gamma * I
        S, I, R = S - 새감염, I + 새감염 - 새회복, R + 새회복
        앓는사람.append(I)
    return 앓는사람

plt.figure(figsize=(7, 3.5))
plt.plot(확산(0.3), label='β = 0.3 (평소)')
plt.plot(확산(0.15), label='β = 0.15 (거리 두기)')
plt.title('앓는 사람 수의 변화 — 곡선 평탄화')
plt.xlabel('날')
plt.ylabel('앓는 사람 수')
plt.legend()
plt.show()

for b in [0.3, 0.15]:
    곡선 = 확산(b)
    print(f'β={b}: 정점 {곡선.index(max(곡선))}일째, {round(max(곡선))}명')`}
</CodeSample>
