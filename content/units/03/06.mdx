## 파이썬으로 그리기

맷플롯립(matplotlib)은 파이썬에서 그래프를 그리는 도구다. 처음 실행하면 맷플롯립(약 12MB)을 받느라 시간이 걸린다. 받기 어려운 교실에서는 **확인된 실행 결과**의 그림을 보며 코드를 읽어도 된다.

### 꺾은선 — 시간에 따른 변화

<CodeSample lang="python" caption="달마다 대여 건수 (꺾은선)" files="bike.csv" plot="u3-l6-line" expect="">
{`import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('bike.csv')
월합계 = df.groupby('월')['대여건수'].sum()

plt.figure(figsize=(7, 3.5))
plt.plot(월합계.index, 월합계.values, marker='o')
plt.title('새솔시 달마다 자전거 대여 건수 (2025)')
plt.xlabel('월')
plt.ylabel('대여 건수')
plt.xticks(range(1, 13))
plt.grid(alpha=0.3)
plt.show()`}
</CodeSample>

### 막대 — 묶음끼리 비교

<CodeSample lang="python" caption="요일별 평균 대여 건수 (막대)" files="bike.csv" plot="u3-l6-bar" expect="">
{`import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('bike.csv')
요일평균 = df.groupby('요일')['대여건수'].mean()
요일평균 = 요일평균.reindex(['월', '화', '수', '목', '금', '토', '일'])

plt.figure(figsize=(7, 3.5))
plt.bar(요일평균.index, 요일평균.values, color='gray')
plt.title('요일별 평균 대여 건수')
plt.ylabel('대여 건수')
plt.show()`}
</CodeSample>

`reindex` 를 빼면 막대가 가나다 차례(금·목·수·월·일·토·화)로 늘어선다. **고치기**를 눌러 그 줄을 지우고 실행해 보자. 요일의 흐름이 사라져 주말이 높다는 것이 잘 안 보인다.

### 산점도 — 두 값의 관계

<CodeSample lang="python" caption="기온과 대여 건수 (산점도)" files="bike.csv" plot="u3-l6-scatter" expect="">
{`import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('bike.csv')

plt.figure(figsize=(6, 4))
plt.scatter(df['평균기온'], df['대여건수'], alpha=0.4)
plt.title('기온과 대여 건수 (점 하나 = 하루)')
plt.xlabel('평균기온(°C)')
plt.ylabel('대여 건수')
plt.show()`}
</CodeSample>

점들이 오른쪽 위로 올라가다가 **25℃ 를 넘으면서 다시 내려온다.** 상관 계수 0.71 이라는 숫자 하나에는 이 «꺾임»이 담기지 않는다. 그래서 숫자와 그래프를 함께 본다.
