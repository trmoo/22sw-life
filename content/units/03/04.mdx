## 파이썬으로 정제하기

실험실에서 한 일을 판다스 코드로 쓰면 이렇다. 단계마다 줄 끝의 설명과 실험실 단추를 견주어 보자.

<CodeSample lang="python" caption="4월 기록 정제하기" files="bike_raw.csv" expect={"처음: (32, 7)\n중복 행: 2\n빈칸: 3\n마지막: (26, 5)\n"}>
{`import pandas as pd

df = pd.read_csv('bike_raw.csv')
print('처음:', df.shape)

df = df.drop(columns=['기록한사람', '메모'])     # ① 필요 없는 열 빼기
print('중복 행:', df.duplicated().sum())
df = df.drop_duplicates()                        # ② 중복 지우기

df['평균기온'] = df['평균기온'].astype(str).str.replace('도', '')    # ③ 단위 떼기
df['평균기온'] = pd.to_numeric(df['평균기온'], errors='coerce')
print('빈칸:', df.isna().sum().sum())
df = df.dropna()                                 # ④ 빈칸 있는 줄 지우기

df = df[df['대여건수'] < 10000]                  # ⑤ 이상한 값 거르기
print('마지막:', df.shape)
df.to_csv('bike_clean.csv', index=False)         # 저장`}
</CodeSample>

32줄 7열이 26줄 5열이 되었다. 중복 2줄, 빈칸이 있던 3줄, 이상한 값 1줄이 빠졌고, 열 2개를 뺐다. `pd.to_numeric(…, errors='coerce')` 는 «숫자로 바꾸되, 못 바꾸는 칸은 빈칸으로 두라»는 뜻이다. 그래서 「도」를 먼저 떼지 않으면 그 칸까지 빈칸이 되어 지워진다 — 실험실 1번 실험에서 본 그대로다.
