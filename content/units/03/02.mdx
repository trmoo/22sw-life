## 생각 열기 — 이 데이터, 어디서 구할까

새솔시 담당자가 자전거 재배치 계획을 세우려면 대여 기록 말고도 데이터가 더 필요하다. 날씨는 어땠는지, 역마다 타고 내리는 사람은 몇 명인지, 동네마다 사는 사람은 몇 명인지 ….

<InfoBox variant="think" label="함께 생각해 보기">
이런 데이터를 시청이 하나하나 직접 재야 할까? 이미 누군가 재어 둔 것은 없을까? 있다면 어디에 있을까?
</InfoBox>

## 찾은 데이터를 쓰기 전에 확인할 것

데이터를 찾았다고 바로 쓰면 안 된다. 내려받기 전에 **데이터의 설명(메타데이터)**을 먼저 읽는다.

<InfoBox variant="warn" label="공개 데이터라도">
누구나 내려받을 수 있다는 것과 «아무렇게나 써도 된다»는 것은 다르다. 출처는 언제나 밝히고, 이용 조건을 지킨다. 또 공개된 데이터를 다른 데이터와 겹쳐 특정한 사람을 알아내려 해서는 안 된다(8차시).
</InfoBox>

## 활용 방안 세우기

데이터를 찾는 일은 «문제»에서 출발해야 한다. 데이터부터 고르면 「재미있는 데이터네」로 끝나기 쉽다.

<Sorter
  title="데이터를 찾아 활용 방안을 세우는 차례"
  items={['풀고 싶은 문제를 한 문장으로 적는다', '문제를 풀려면 어떤 값이 필요한지 적는다', '그 값을 가졌을 만한 플랫폼에서 찾는다', '설명(기관·기간·열의 뜻·이용 조건)을 확인한다', '이 데이터로 무엇을 알아내 어떻게 쓸지 적는다']}
  explain="문제 → 필요한 값 → 찾기 → 확인 → 활용 방안. 확인 단계를 건너뛰면, 다 분석한 뒤에야 「이 열이 그런 뜻이 아니었네」를 알게 된다."
/>
