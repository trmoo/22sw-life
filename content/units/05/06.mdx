## 첫 판 만들기 — 등록과 찾기

5차시에 설계한 데이터와 알고리즘을 그대로 코드로 옮긴다. 분실물 하나는 딕셔너리, 분실물 전체는 리스트다. ▶ 실행해 보자.

<CodeSample lang="python" caption="분실물 찾기 — 첫 판" expect={"체육복 · 남색 · 체육관\n체육복 바지 · 검정 · 운동장\n"}>
{`# 분실물 찾기 — 첫 판(최소 기능 제품): 등록하기와 찾기 두 가지만
분실물 = []

def 등록(물건, 색, 곳):
    분실물.append({'물건': 물건, '색': 색, '곳': 곳})

def 찾기(낱말):
    결과 = []
    for 하나 in 분실물:
        if 낱말 in 하나['물건']:
            결과.append(하나)
    return 결과

등록('체육복', '남색', '체육관')
등록('필통', '분홍', '3층 복도')
등록('체육복 바지', '검정', '운동장')

for 하나 in 찾기('체육복'):
    print(하나['물건'], '·', 하나['색'], '·', 하나['곳'])`}
</CodeSample>

잘 되는 것 같다. 그런데 «잘 되는 것 같다»는 시험이 아니다.

## 시험표로 확인하기

<Term ko="테스트" en="test" desc="프로그램에 입력을 넣고, 기대한 결과와 실제 결과가 같은지 확인하는 일" />는 **입력 · 기대한 결과 · 실제 결과**를 나란히 놓고 견주는 일이다. 시험 역할은 «평범한 경우»뿐 아니라 **이상한 경우**를 일부러 찾는다 — 없는 물건, 띄어 쓴 낱말, 아무것도 안 적은 경우.

<CodeSample lang="python" caption="첫 판의 시험표" expect={"통과 | 있는 물건 | 기대 1 실제 1\n통과 | 여러 개 | 기대 2 실제 2\n통과 | 없는 물건 | 기대 0 실제 0\n실패 | 띄어 쓴 낱말 | 기대 2 실제 0\n실패 | 빈칸만 넣음 | 기대 0 실제 3\n"}>
{`분실물 = []

def 등록(물건, 색, 곳):
    분실물.append({'물건': 물건, '색': 색, '곳': 곳})

def 찾기(낱말):
    결과 = []
    for 하나 in 분실물:
        if 낱말 in 하나['물건']:
            결과.append(하나)
    return 결과

등록('체육복', '남색', '체육관')
등록('필통', '분홍', '3층 복도')
등록('체육복 바지', '검정', '운동장')

# 시험표 — 입력 · 기대한 결과 · 실제 결과를 견준다
def 시험(무엇, 실제, 기대):
    print('통과' if 실제 == 기대 else '실패', '|', 무엇, '| 기대', 기대, '실제', 실제)

시험('있는 물건', len(찾기('필통')), 1)
시험('여러 개', len(찾기('체육복')), 2)
시험('없는 물건', len(찾기('우산')), 0)
시험('띄어 쓴 낱말', len(찾기('체육 복')), 2)
시험('빈칸만 넣음', len(찾기('')), 0)`}
</CodeSample>

두 가지가 실패했다. 이것이 시험의 쓸모다.

- **띄어 쓴 낱말** — 「체육 복」에는 띄어쓰기가 있어 「체육복」 안에 들어 있지 않다. 사람은 같은 말로 보지만 컴퓨터는 글자를 그대로 견준다.
- **빈 낱말** — 파이썬에서 빈 글자 `''` 는 **모든 글자 안에 들어 있다**고 본다. 그래서 아무것도 안 적으면 모든 물건이 나온다. 5차시 알고리즘 설계에서 «아무것도 남지 않았으면 알리고 끝낸다»를 넣어 둔 까닭이다.

<CodeSample lang="python" caption="고친 판 — 띄어쓰기를 지우고, 빈 낱말을 걸러 낸다" expect={"통과 | 있는 물건 | 기대 1 실제 1\n통과 | 여러 개 | 기대 2 실제 2\n통과 | 없는 물건 | 기대 0 실제 0\n통과 | 띄어 쓴 낱말 | 기대 2 실제 2\n통과 | 빈칸만 넣음 | 기대 0 실제 0\n"}>
{`분실물 = []

def 등록(물건, 색, 곳):
    분실물.append({'물건': 물건, '색': 색, '곳': 곳})

def 다듬기(글):
    return 글.replace(' ', '')   # 띄어쓰기를 모두 지운다

def 찾기(낱말):
    낱말 = 다듬기(낱말)
    if 낱말 == '':
        return []                # 아무것도 안 적으면 찾지 않는다
    결과 = []
    for 하나 in 분실물:
        if 낱말 in 다듬기(하나['물건']):
            결과.append(하나)
    return 결과

등록('체육복', '남색', '체육관')
등록('필통', '분홍', '3층 복도')
등록('체육복 바지', '검정', '운동장')

def 시험(무엇, 실제, 기대):
    print('통과' if 실제 == 기대 else '실패', '|', 무엇, '| 기대', 기대, '실제', 실제)

시험('있는 물건', len(찾기('필통')), 1)
시험('여러 개', len(찾기('체육복')), 2)
시험('없는 물건', len(찾기('우산')), 0)
시험('띄어 쓴 낱말', len(찾기('체육 복')), 2)
시험('빈칸만 넣음', len(찾기('')), 0)`}
</CodeSample>

<InfoBox variant="tip" label="고친 뒤에도 시험표 전체를 다시 돌린다">
한 곳을 고치면 다른 곳이 고장 나기도 한다. 그래서 시험표를 코드로 남겨 두고, **고칠 때마다 처음부터 다 돌린다.** 이번에도 앞의 세 시험이 여전히 통과하는지 함께 확인했다.
</InfoBox>
