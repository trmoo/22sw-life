## 생각 열기 — 「어두우면」은 몇부터일까

스마트 가로등은 「어두우면 켠다」. 그런데 소프트웨어는 「어둡다」는 말을 모른다. 숫자만 안다.

<InfoBox variant="think" label="함께 생각해 보기">
빛 센서 값이 0~1023이라면, 몇보다 작을 때를 「어둡다」로 정해야 할까? 해 질 녘의 값은? 구름 낀 낮의 값은? 그 기준을 너무 높게 잡으면, 너무 낮게 잡으면 각각 어떤 일이 생길까?
</InfoBox>

## 규칙의 세 부품 — 조건, 기준, 되풀이

<Term ko="문턱값" en="threshold" desc="센서 값이 그보다 크냐 작으냐로 판단을 가르는 기준값. 「빛이 300보다 작으면 어둡다」의 300" />은 센서 값으로 판단을 가르는 기준이다. 사람의 말(「어두우면」)을 소프트웨어의 말(「빛 &lt; 300」)로 옮기는 자리가 바로 여기다.

]} />

가상 보드의 **진짜 보드에 올릴 코드 보기**를 열면 이 세 부품이 코드에서 어디에 있는지 보인다. 마이크로비트로 만든 스마트 가로등의 코드는 이런 모양이다.

```python
while True:                                   # 되풀이 — 끝없이 다시
    if display.read_light_level() < 60:       # 조건 + 문턱값(60)
        for i in range(8):
            np[i] = (255, 255, 255)           # 그러면 — 흰색으로 켜기
        np.show()
    else:                                     # 아니면 — 끄기
        for i in range(8):
            np[i] = (0, 0, 0)
        np.show()
    sleep(100)                                # 0.1초 쉬고 다시
```

아두이노에서는 `while True:` 대신 `void loop() { … }` 가 되풀이를 맡는다. 말은 달라도 뼈대는 같다.

<InfoBox variant="warn" label="보드를 바꿨더니 실패했다면">
마이크로비트에서 「빛이 60보다 작으면」으로 성공한 규칙을 아두이노로 옮기면, 아두이노의 빛 값은 0~1023이라 60은 «거의 깜깜한 밤»에 해당한다. 문턱값은 **그 보드의 범위에 맞춰** 다시 정해야 한다. 센서 패널의 슬라이더 아래에 범위가 적혀 있다.
