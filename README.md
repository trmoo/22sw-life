# 소프트웨어와 생활 — 웹 교과서

2022 개정 교육과정 고등학교 정보과 **융합 선택 과목 「소프트웨어와 생활」** 웹 교과서입니다.

- 주소: https://trmoo.github.io/22sw-life/
- 다섯 단원 · 36차시 · 성취기준 19개 (`[12소생01-01]` ~ `[12소생05-04]`)

| 단원 | 내용 | 상태 |
|---|---|---|
| Ⅰ 세상을 변화시키는 소프트웨어 | 소프트웨어와 사회 변화, 미래 예측, 학문 분야·지역 사회의 융합 | **집필 완료(검토 중)** |
| Ⅱ 창작을 지원하는 소프트웨어 | 피지컬 컴퓨팅(마이크로비트·아두이노 가상 보드), 미디어 아트, 웨어러블 | **집필 완료(검토 중)** |
| Ⅲ 현상을 분석하는 소프트웨어 | 데이터 플랫폼·수집·정제·분석·시각화·해석, 데이터 윤리(비식별화·편향) | **집필 완료(검토 중)** |
| Ⅳ 모의 실험하는 소프트웨어 | 시뮬레이션의 구성 요소·가치·활용·설계·모델링, 확률(몬테카를로)·확산(SIR) 구현 | **집필 완료(검토 중)** |
| Ⅴ 가치를 창출하는 소프트웨어 | 스타트업 개념·사례, 사용자 요구 분석(페르소나), 린 캔버스, 협력 설계(시안·작업 보드), 최소 기능 제품·시험, 가치 평가 | **집필 완료(검토 중)** |

## 수업에서 쓰는 법

1. 왼쪽 단원 목록에서 차시를 고릅니다. 화면을 교실 TV·전자칠판에 띄워 함께 읽습니다.
2. 비교판·영향 저울·분류하기·순서 맞추기 같은 활동은 눌러 보며 바로 확인합니다.
   Ⅱ단원의 **가상 보드**는 장치 없이 센서 값을 바꿔 가며 규칙을 시험하고, 같은 규칙을
   진짜 마이크로비트(MicroPython)·아두이노(C++) 코드로 보여 줍니다.
   Ⅲ단원의 **실험실**(정제·분석·그래프 고르기·비식별화)은 인터넷 없이도 돌아가고,
   파이썬 예제는 **판다스·맷플롯립이 브라우저 안에서 실제로 실행**됩니다
   (처음 실행할 때 약 20MB 를 받습니다. 학교망에서 막히면 「확인된 실행 결과」를 보며 따라갑니다).
   Ⅳ단원의 **시뮬레이터**(대여소의 하루·급식 줄·원주율 점 던지기·감염병 확산)도 인터넷 없이 돌아갑니다.
   변수를 바꿔 여러 번 돌리고, 지난 실험과 견주어 볼 수 있습니다.
   Ⅴ단원은 팀 프로젝트 한 바퀴입니다. **페르소나 → 린 캔버스 → 눌러 보는 시안·작업 보드 → 가치 평가표**가
   차시를 따라 이어지고(앞 차시에 만든 것을 불러와 이어 씁니다), 시안은 HTML 파일로 내려받아
   친구의 휴대 전화에서 눌러 보게 할 수 있습니다. 팀원 이름 대신 별명을 씁니다.
3. 활동지는 그 브라우저에 자동 저장되고, **[⬇ 내려받기]** 로 HTML 파일을 받아 제출합니다.
   공용 컴퓨터에서는 마치고 **[지우기]** 를 두 번 누릅니다.

상단의 **교과서 선택**에서 학교 교과서를 고르면 단원마다 그 교과서의 위치(쪽수)가 함께 보입니다.

## 개발

```bash
npm install
npm start          # 개발 서버
npm test           # 데이터·본문·목차·예제 점검
npm run build      # 점검 → dist/ 빌드 → 산출물 전수 검사
npm run data       # Ⅲ단원 연습용 데이터 다시 만들기 (python + pandas)
```

`npm test` 의 예제 점검은 파이썬 예제를 실제로 실행합니다. Ⅲ단원 예제를 돌리려면
파이썬에 `pandas`·`matplotlib` 이 있어야 하고, 맷플롯립 예제의 그림은 이때 `public/figs/` 에 저장됩니다.
